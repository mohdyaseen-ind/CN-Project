# OSI / TCP-IP evidence notes

- DNS: Application layer, UDP 53
- HTTP: Application layer
- TLS: between application and transport in the course mapping
- TCP: Transport layer
- UDP: Transport layer
- IP: Network layer
- Ethernet/Wi-Fi: Link layer

Key packet evidence:
1. DNS query/response
2. TCP SYN -> SYN/ACK -> ACK
3. TLS handshake
4. Encrypted application data
5. HTTP headers / caching
